# Luxe Dental Clinic

Premium redesign concept for **Luxe Dental Clinic** — a private dental clinic in Al Hudaiba, Dubai, UAE.

## Stack

- React + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Project structure

```
src/
  components/
    layout/     # Navbar, Footer, Logo
    sections/   # Page sections
    ui/         # Reusable UI primitives
  data/         # Clinic copy & content
  App.jsx
  main.jsx
  index.css
```
